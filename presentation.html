PRODUCT OVERVIEW
產品概述
TRACE 是一套即時全球情報儀表板，將分散於全球各地的新聞報導、地緣事件與環境資料， 融合為單一視覺化介面，讓使用者一眼掌握世界對台灣的關注全貌。

新聞框架分類
全球新聞聚合
透過 GDELT DOC API 與 Google News RSS 雙層擷取，將全球數十國的新聞報導即時匯聚至地圖上，並按國家自動分群。
互動式世界地圖
以 Leaflet 為基礎的互動地圖，支援縮放、平移、圖層切換，將新聞、事件、航道與氣象四層資料疊加呈現。
AI 敘事簡報
自動分析新聞框架與主題趨勢，生成三大核心敘事、區域情感差異與關鍵頭條摘要，並支援自然語言問答。
搜尋審計追蹤
每次查詢均記錄資料來源、延遲時間、記錄數量與狀態，形成完整審計日誌，確保資料可溯源、可驗證。

USER EXPERIENCE — PART 1
使用者體驗：搜尋與地圖互動
使用者輸入關鍵字後，系統即時從 GDELT 與 RSS 擷取新聞， 將結果以彩色圓點標記在全球地圖上，每個圓點的大小反映報導數量，顏色代表新聞框架類型。

搜尋流程

01
關鍵字輸入
在頂部搜尋列輸入任意主題（如 Taiwan、TSMC、Strait tensions），按 Enter 或點擊搜尋按鈕。
02
多層資料擷取
系統依序查詢 GDELT DOC API，若結果不足則自動補充 Google News RSS，最終備有內建模擬資料集作為兜底。
03
視覺化呈現
新聞按來源國家分群，以 CircleMarker 標示於地圖。圓點大小隨報導數量動態調整，顏色對應經濟（藍）、軍事（紅）、外交（綠）三類框架。
04
互動瀏覽
點擊圓點可展開彈出視窗，顯示該國最新頭條與環境情境分頁；滑鼠懸停顯示國家名稱與報導數量的快速預覽。

地圖操作

05
平滑縮放與導航
支援滑鼠滾輪平滑縮放，左上角提供放大、縮小、重置全球視角與一鍵聚焦台灣四組導航按鈕。
06
底圖主題切換
提供 Dark（OSINT 深色）與 Light（Voyager 淺色）兩種底圖風格，一鍵切換以適應不同場景需求。
07
框架分布概覽
地圖右上角即時顯示經濟、軍事、外交三類框架的占比條形圖，讓使用者快速掌握整體報導傾向。
08
查詢資訊覆蓋層
地圖左上角顯示當前查詢關鍵字、文章總數、涵蓋國家數與擷取時間，所有覆蓋層均為半透明浮動面板，不遮擋地圖操作。
03 / 10 使用者體驗
USER EXPERIENCE — PART 2
使用者體驗：AI 敘事簡報
右側 AI 面板將龐雜的新聞資料轉化為結構化情報， 使用者一鍵生成摘要後，可透過自然語言問答深入探索特定面向。
核心敘事主題
系統掃描所有新聞標題，比對六大利害關係主題模式（科技供應鏈、海峽軍事、兩岸外交、全球貿易、區域安全聯盟、國會交流），按提及次數排序取出前三大主題，讓使用者一眼掌握當日報導焦點。
區域情感差異分析
將新聞來源分為西方媒體與亞洲媒體兩大群組，比較雙方在軍事、經濟、外交三類框架上的報導比重，生成一段敘述性分析，揭示不同區域如何看待同一事件。
關鍵浮現頭條
從前 20 篇文章中，優先挑選不同國家的報導以確保地理多樣性，彙整為八則關鍵頭條清單，協助使用者快速掃描當日最重要的浮現議題。
Q&A
自然語言追問
摘要生成後，使用者可在底部輸入框以英文提問，例如「Why is there a spike in news from Japan?」或「How does Western vs Asian coverage differ?」。 系統會根據當前資料集生成結構化回覆，涵蓋國家別分析、軍事框架占比、經濟供應鏈焦點、情感差異等面向。 面板亦提供四組建議問題按鈕，降低使用者的冷啟動門檻。

DESIGN PHILOSOPHY
設計理念
TRACE 的設計遵循五大核心原則，從視覺美學到資料治理， 每一層面都服務於「讓情報使用者更高效地理解世界」這一目標。
01
OSINT 情報美學
整體視覺語言取材自專業情報分析工具——深色底圖、琥珀色高亮、等寬字型標示數據、 紅色脈動指示器標示即時狀態。所有 UI 元素採用半透明浮動面板設計， 讓地圖始終保持為視覺主體，覆蓋層則如情報標注般懸浮其上。 圓點大小、顏色編碼與虛線樣式均有明確的語意對應，使用者無需手冊即可直覺理解。
02
多層資料融合
新聞、事件、航道、氣象四種異質資料來源在同一地圖上疊加呈現， 使用者可自由組合圖層以建構不同分析視角。 彈出視窗採用分頁設計（Headlines / Env Context）， 在不增加視覺負荷的前提下，讓單一地標承載多重維度的資訊。
03
可審計的資料治理
每次搜尋均產生完整的審計日誌，記錄資料來源名稱、查詢字串、記錄數量、延遲毫秒數與狀態標記。 頂部「Search Status: Verified」徽章提供一鍵查驗入口。 這確保所有呈現給使用者的資料均可回溯至原始 API 呼叫， 符合情報分析的可驗證性要求。
04
漸進式資訊揭露
介面設計遵循「概覽先於細節」的原則——先以地圖圓點呈現全球分布概況， 滑鼠懸停顯示國家與數量的快速預覽，點擊後才展開完整頭條列表與環境情境。 AI 面板同樣先提供一鍵摘要按鈕，生成後才顯示建議問題與對話輸入框。 這種漸進式揭露降低了使用者的認知負荷。
05
優雅降級與韌性
資料擷取採三層備援機制：GDELT DOC API 為首選，不足時自動補充 Google News RSS， 兩者皆失敗時啟用內建模擬資料集。審計日誌忠實記錄每一層的嘗試結果， 即使在降級模式下使用者仍能體驗完整功能。 這確保系統在各種網路條件下皆可運作。
06
回應式互動設計
所有互動元素均提供即時視覺回饋——搜尋時顯示載入動畫， 圓點 hover 時展示 Tooltip，圖層切換時圓點帶光暈效果， 底圖切換即時改變整體配色。AI 面板可收合為側邊窄條， 釋放地圖空間。這些微互動讓系統感覺敏銳且專業。
